# Java Interview Notes

Структурированные заметки по Java-экосистеме для подготовки к техническим собеседованиям. Содержит теорию, примеры кода, схемы и шпаргалки по ключевым темам.

> Этот репозиторий — личная база знаний, оформленная в виде Obsidian Vault. Вы можете открыть её в Obsidian или читать напрямую через GitHub.

---

## Структура репозитория

```
obsidian-vault/
├── Java/
│   ├── Java.md              # Java SE (Core, OOP, Collections, Concurrency, JMM, GC)
│   ├── Spring.md            # Spring Framework & Boot
│   ├── DB-SQL.md            # SQL и реляционные БД
│   ├── DB-ORM.md            # JPA / Hibernate
│   ├── Architecture.md      # Архитектура и messaging
│   ├── Reactive.md          # Реактивное программирование (WebFlux, Reactor, R2DBC)
│   ├── Design-Patterns.md   # Паттерны проектирования в Spring-приложениях
│   ├── Development-Process.md # Agile, Scrum, Kanban
│   ├── DevOps.md            # DevOps инструменты
│   ├── HTTP & Web.md        # Сети и веб
│   ├── Testing.md           # Тестирование
│   ├── Concurrent/          # Примеры кода: синхронизаторы и concurrent-коллекции
│   └── Resources/           # Изображения, диаграммы, гифки
└── README.md                # Этот файл
```

---

## Как использовать

### В браузере (GitHub)
Все заметки написаны в Markdown — открывайте прямо на GitHub через веб-интерфейс.

### В Obsidian
1. Склонируйте репозиторий;
2. Откройте папку `obsidian-vault` как Vault в Obsidian;
3. Все ссылки, изображения и Mermaid-диаграммы будут работать корректно.
